アクター状態の切り替え ​

機能説明 ​

指定したアクターの状態を切り替えます。安全な状態フレームを提供できるキャラクターは新旧の画面をブレンドし、それ以外はフェードアウト、状態適用、フェードインへ自動的にフォールバックします。トランジション完了後にストーリーを続行します。

構文 ​

text
actor change <キャラクター名> <新しい状態>

パラメーター ​

パラメーター必須例説明
キャラクターはいkona状態を切り替えるアクター名
新しい状態はいhappy切り替え先の新しい状態

例 ​

text
actor change kona happy

状態切り替えトランジション ​

actor change はトランジション方式を自動的に選択します。

  1. 現在と対象の状態フレームを提供できる場合は、プリマルチプライド Alpha シェーダーで画素をブレンドします。
  2. 安全な状態フレームを提供できない場合は、現在のアクターをフェードアウトし、状態を適用してフェードインします。
  3. トランジションの完了後、次のストーリーコマンドを実行します。

KonadoStageController ノードのインスペクターでトランジションを設定できます。

プロパティデフォルト説明
actor_state_transition_enabledtrueアクターの状態切り替えでフェードを有効にします
actor_state_transition_duration0.3トランジション全体の秒数です。安全なフォールバックではフェードアウトとフェードインで半分ずつ使用します

actor_state_transition_enabled を無効にするか、actor_state_transition_duration を 0 にすると、状態は即座に切り替わります。

トランジションはキャラクターシーンを複製しません。付属の AnimatedSprite2D サンプルは純粋なテクスチャ状態フレームで本当のブレンドを行います。独自の状態フレームは、一部の表示要素だけでなくキャラクター全体の画面を表す必要があります。動画、Spine、Live2D、安全で完全な状態フレームを提供できない独自シーンは自動的にフォールバックするため、スクリプト、音声、動的メディアが二重に実行されません。対象のアクターが存在しない場合や状態を適用できない場合でも、コマンドを完了してストーリーを続行します。
