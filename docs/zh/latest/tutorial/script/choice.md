# 选项跳转

## 功能概述

该功能需与**分支功能**搭配使用，核心作用是在交互选项标签中配置跳转逻辑。点击对应选项后可直接跳转到指定分支。每个 `choice` 语句创建一个选项，多个相邻的 `choice` 行会被合并为一个选项组，同时展示。

选项可选地带一个**可见条件**（`if`）和**一次性标记**（`once`），用来表达“好感度足够才出现”“问过一次就不再出现”这类常见需求。

## 语法规范

```text
choice "选项内容" -> 分支名称 [if %变量 运算符 值] [once]
```

| 参数 | 必填 | 示例 | 说明 |
|------|------|------|------|
| 选项内容 | 是 | `"选择咖啡"` | 交互时展示的选项文本 |
| 分支名称 | 是 | `coffee_choice` | 需跳转的目标分支唯一标识 |
| `if` 条件 | 否 | `if %love >= 5` | 条件成立时才显示该选项 |
| `once` | 否 | `once` | 选中一次后不再出现 |

`if` 与 `once` 的顺序任意，但各自最多出现一次。条件支持与 `if` 语句相同的六种比较运算符，右值可以是数字、字符串、布尔值或变量。

## 使用示例

每个选项单独一行：

```text
choice "Green tea" -> green_tea
choice "Black tea" -> black_tea
```

带条件与一次性选项：

```text
choice "送花（好感+10）" -> gift_flower
choice "送书（好感+5）" -> gift_book if %love >= 5
choice "（已问过）镇上的传闻" -> rumor
choice "（只问一次）神秘商人" -> merchant once
choice "什么都不送" -> gift_none
```

## 行为说明

- **条件不成立**：选项被隐藏；如果整个选项组没有任何可用项，会**直接继续执行选择组之后的语句**，不会显示空菜单。
- **条件变量不存在或类型不兼容**：按“条件不成立”处理，并只在控制台警告一次，不会打断剧情。
- **`once` 的身份**：由“choice 指令稳定键 + 目标分支稳定键 + 组内序号”组成，因此切换语言或修改选项文案不会让“已选过”失效；重排选项会被视为新的选项。
- **回退与存档**：`once` 的使用记录属于运行期状态，会随“上一句”回退、检查点和存档一起还原；`init_dialogue()` 开始新游戏时会清空。
- **命名参数**：选项组的命名参数（例如 `[id=...]`）只能写在第一项。

## 注意事项

1. 分支名称需与剧本中定义的分支标识完全一致，区分大小写，不可包含空格或特殊符号。
2. 选项内容需用英文双引号包裹。
3. `->` 是选项与分支名称之间的分隔符，不可省略。
4. `once` 记录的是“这个菜单项”，不是“这个分支”；不同菜单里指向同一分支的选项互不影响。
